### **==클로드 프로젝트란?==**

나만의 **데이터를 학습**시킨 **특화된 채팅 모델**!

매번 채팅창마다 나만의 데이터를 학습시킬 필요 없이 나만의 카피라이터, 컨텐츠 마케터, 나만의 상담가, 나만의 개발자 , 혹은 나만의 사이드프로젝트 팀 등을 만드는게 가능합니다.

## 클로드 프로젝트 기능 사용하기

프로젝트에 입장하는 방법은 클로드 왼쪽 창을 열면 새 채팅 시작 바로 밑칸에 ‘프로젝트’ 카테고리가 있습니다.

![제목을 입력해주세요 001 5 1](https://www.gotai.co.kr/wp-content/uploads/2025/03/%EC%A0%9C%EB%AA%A9%EC%9D%84-%EC%9E%85%EB%A0%A5%ED%95%B4%EC%A3%BC%EC%84%B8%EC%9A%94_-001-5-1-1024x248.jpg "나만을 도와주는 직원 만들기, 클로드 프로젝트 기능 1")

프로젝트 카테고리에 입장하면 그간 만들고 있는 프로젝트들을 중앙 화면에서 볼 수 있고, 오른쪽에 ‘프로젝트 생성’버튼을 클릭해도 새로운 프로젝트를 만들 수 있습니다.

![클로드 프로젝트 생성](https://www.gotai.co.kr/wp-content/uploads/2025/03/%EC%BA%A1%EC%B2%98_2025_03_16_08_15_17_175.png "나만을 도와주는 직원 만들기, 클로드 프로젝트 기능 2")

프로젝트 생성 버튼을 누르면 이와 같은 화면이 등장하는데요. 본인이 알아 볼 수 있는 텍스트로 작성하면 됩니다. 중요한건 아니니까 간단한 목표만 적어주세요.

![클로드 프로젝트의 인터페이스](https://www.gotai.co.kr/wp-content/uploads/2025/03/%EC%BA%A1%EC%B2%98_2025_03_16_08_10_08_225.png "나만을 도와주는 직원 만들기, 클로드 프로젝트 기능 3")

자 그러면 이제 이런 창이 뜨게 되는데, 왼쪽은 일반 클로드처럼 채팅을 하는 공간이고, 오른쪽 공간이 중요한데요.

오른쪽 공간은 다음의 두 기능으로 나누어 집니다.

- **==프로젝트 지침 설정==** : AI에게 어떤 역할을 부여할 것인지, 어떤 방식으로 대답하게 할 것인지를 부여하는 기능입니다. **==“어떻게”==**를 담당한다고 생각하시면 됩니다.
- **==데이터 업로드==** : AI에게 어떤 정보들을 미리 학습시킬 것인지에 대한 부분입니다. **==“무엇을”==**을 담당한다고 생각하시면 됩니다.

### 프로젝트 지침 예시

**==프로젝트 지침은 클로드 프로젝트에서 가장 중요한 기능==**입니다. 똑같은 데이터를 첨부했더라도 지침에 따라 답변은 천차만별로 달라질 수 있죠. 예시로 어떤 지침들을 설정할 수 있을까요?

**==첫번째로 역할 부여==**를 할 수 있겠는데요

“당신은 고등학생을 위한 수학 튜터입니다. 문제 풀이 과정을 상세히 설명하고, 학생이 스스로 생각할 수 있도록 힌트를 제공하세요. 복잡한 개념은 일상적인 예시를 통해 설명해주세요.”

“당신은 외국어 학습 코치입니다. 문법 오류를 친절하게 교정해주고, 자연스러운 표현을 제안하며, 학습자의 수준에 맞게 대화를 이끌어주세요.”

이런식으로 **==역할부여 + 대답방식==**을 부여하는 방법이 있겠습니다.

**==두번째로==** XML 구조의 지침 작성의 방식이 있겠는데요

```
<agent>
  <role>당신은 심층 연구 분석가입니다.</role>
  <goals>
    <goal>주제에 대한 포괄적인 리서치 수행</goal>
    <goal>핵심 통찰력과 패턴 식별</goal>
    <goal>데이터 기반 결론 도출</goal>
  </goals>
  <workflow>
    <step id="1">
      <name>문제 정의</name>
      <action>연구 질문을 명확히 정의하고 범위를 설정합니다.</action>
      <output>명확한 연구 목표와 질문</output>
    </step>
    <step id="2">
      <name>데이터 수집</name>
      <action>관련 정보를 체계적으로 수집합니다.</action>
      <output>구조화된 데이터 요약</output>
    </step>
    <step id="3">
      <name>분석 실행</name>
      <action>수집된 정보를 다양한 관점에서 분석합니다.</action>
      <output>주요 분석 결과</output>
    </step>
    <step id="4">
      <name>결론 도출</name>
      <action>발견된 인사이트를 종합하여 결론을 제시합니다.</action>
      <output>핵심 발견점 및 결론</output>
    </step>
  </workflow>
  <output_format>
    <summary>연구 요약 (250단어 이내)</summary>
    <key_findings>표 형식의 주요 발견점</key_findings>
    <analysis>심층 분석 (섹션별 구분)</analysis>
    <references>참고 자료 목록</references>
  </output_format>
</agent>
```

위 XML 태그를 이용한 구조화된 문장은 AI에게 역할을 부여하고 Workflow를 지정해주는 프롬프트 입니다. **==XML구조를 AI가 더 잘 이해==**하기 때문에 습관을 들이시면 좋은 프롬프팅 방법입니다.

하는 방법은 간단합니다. **==“내가 방금한 질문을 최고의 답변을 하기위한 XML 태그를 이용한 질문 프롬프트로 변경해줘”==**

라고 요청하면 이러한 형태로 클로드가 변경해서 입력해줍니다!

### 데이터 업로드

![캡처 2025 03 20 07 23 07 867](https://www.gotai.co.kr/wp-content/uploads/2025/03/%EC%BA%A1%EC%B2%98_2025_03_20_07_23_07_867.png "나만을 도와주는 직원 만들기, 클로드 프로젝트 기능 4")

데이터 업로드는 현재 **==GitHub과 Google Drive는 연동==**되어있기 때문에 바로 파일을 입력시킬 수 있으며, 업로드로도 가능한데요

업로드로는 다음과 같은 파일을 업로드 할 수 있습니다.

**문서파일** : PDF, Word(.docx, .doc), 텍스트 파일(.txt), 마크다운(.md)  
**데이터 파일**: CSV, Excel 스프레드시트(.xlsx, .xls), JSON  
**이미지 파일**: PNG, JPEG, GIF, SVG  
**코드 파일**: Python, JavaScript, HTML, CSS 등 다양한 프로그래밍 언어 파일

거의 모든 데이터를 집어 넣어서 분석할 수 있습니다.

제가 **==추천드리는 Tip==**은 바로 데이터를 업로드 하는게 아니라, 일단 클로드 일반 채팅창에 모든 텍스트를 붙여 넣은후 클로드 프로젝트에서 잘 참고하게끔 **==데이터를 구조화해달라고 부탁==**하는 과정을 거친 후 넣는 겁니다.

![캡처 2025 03 20 07 29 08 33](https://www.gotai.co.kr/wp-content/uploads/2025/03/%EC%BA%A1%EC%B2%98_2025_03_20_07_29_08_33.png "나만을 도와주는 직원 만들기, 클로드 프로젝트 기능 5")

그러면 이런식으로 클로드에서 **==깔끔하게 데이터 정리==**를 해주는데, 이러한 형태로 데이터를 학습시키는게 조금 더 **==최적화에 도움==**이 되는 것 같았습니다.

### 프로젝트 사용 지침 예시 1

![캡처 2025 03 16 14 23 06 737](https://www.gotai.co.kr/wp-content/uploads/2025/03/%EC%BA%A1%EC%B2%98_2025_03_16_14_23_06_737.png "나만을 도와주는 직원 만들기, 클로드 프로젝트 기능 6")

**==<클로드 프로젝트에 학습 시킨 데이터>==**

```
칼 로저스의 심리 상담 기법을 사용해야함. 
핵심 철학
로저스는 모든 사람이 자기 실현의 경향성을 가지고 있으며, 적절한 환경이 주어지면 스스로 성장하고 문제를 해결할 능력이 있다고 믿었습니다.
상담자의 핵심 태도

무조건적 긍정적 존중(Unconditional Positive Regard): 내담자를 판단하지 않고 있는 그대로 수용합니다.
공감(Empathy): 내담자의 주관적 경험과 감정을 그들의 관점에서 이해하려고 노력합니다.
진정성(Genuineness): 상담자는 방어적이거나 가식적이지 않고 진실된 자신으로서 내담자와 관계를 맺습니다.

상담 과정

관계 형성: 신뢰 관계를 구축하는 것을 최우선으로 합니다.
반영적 경청: 내담자의 말을 주의 깊게 듣고, 그들의 감정과 생각을 반영해 돌려줍니다.
비지시적 접근: 조언이나 해석을 제공하기보다는 내담자가 스스로 자신의 문제를 탐색하고 해결책을 찾도록 돕습니다.
현재 중심: 과거보다는 현재의 경험과 감정에 초점을 맞춥니다.

상담 기법

감정 반영: "지금 많이 좌절감을 느끼고 계시는 것 같군요."
명료화: "그 경험이 당신에게 어떤 의미였나요?"
개방형 질문: "그 상황에서 어떤 느낌이 들었나요?"
요약하기: "지금까지 이야기한 내용을 정리해보면..."
```

저는 위와 같은 텍스트를 입력시킨 저만의 상담가 클로드 프로젝트를 만들었습니다. 그럼 이 텍스트를 학습한 프로젝트에서의 대화창과 일반 대화창의 차이가 있는지 살펴볼게요.

**==<학습 시키지 않은 일반 대화창>==**

둘다 질문은 똑같습니다만, 일반 대화창은 바로 한번에 해결방법을 제시해주는 반면, 칼 로저스의 심리 상담방법을 학습한 클로드 프로젝트는 정말로 상담하는 듯한 느낌으로 저에게 더 많은 정보를 요구하는 걸 관찰 할 수 있었습니다.

사용지침을 어떻게 만드느냐에 따라 결과물의 차이가 상당하죠?

### 프로젝트 사용지침 예시 2

제가 유튜브 채널의 운영을 도움 받기 위해 유튜브 데이터의 거의 모든 것과 아래에서 소개드릴 Agentic workflow의 사용지침을 넣은 영상입니다.

유튜브 채널 데이터로 꽤 많은 양을 넣었는데 용량의 2%인것을 보면 사용에 문제는 없을것 같습니다.

사전학습시킨 데이터로 채널의 약점과 기회, 운영 가이드를 작성해달라고 했을때의 결과입니다.

결과가 굉장히 놀라운데요!

첫번째 개별 문서로 (다운로드 가능한) 채널의 **==분석 및 운영 전략 페이지==**를 만들어줍니다  
두번째로 앞서 문서를 이용한 **==직관적인 그래프 이미지 파일==**을 만들어줍니다.  
세번째로는 왼쪽 ==**대화창에서 요약 데이터**==를 나타내줍니다.

어떤가요? 클로드 프로젝트 꼭 써야겠죠? 결과물이 제로샷프롬프트와 비교해서 천지차이니까요

## 클로드 프로젝트 사용하기 – 심화

앞서 기본 내용을 실행해 보셨나요? 그럼 프로젝트에 사용할 수 있는 **==흥미로운 심화버전의 사용 지침==**을 소개해드리겠습니다. 바로 Agentic Workflow를 적용한 사용 지침을 만들어 보는 것인데요.

### Agentic Workflow – 가상의 여러 팀원을 생성하기

Agentic workflow는 **==앤드류응이라는 교수가 제안한 방법==**으로, 한 번에 답을 얻는 것이 아닌 클로드같은 **==LLM이 생각,연구, 수정을 거듭 반복하게 해서 답변의 퀄리티를 높이는 방법==** 입니다.

이걸 어떻게 사용해야 하냐? **==다음과 같은 텍스트==**를 프로젝트의 사용지침으로 추가 시키면 됩니다.

```
"질문에 답할 때, 당신은 4명의 가상 전문가로 구성된 팀을 만들어 주세요:

민수 = 데이터 분석가 (객관적 데이터와 통계를 중시)
가영 = 창의적 전략가 (혁신적이고 대안적인 관점 제시)
하윤 = 비판적 사고가 (잠재적 문제점과 오류 지적)
민지 = 실무 전문가 (현실적 적용과 실행 계획 중시)

각 전문가가 내 질문을 자신의 관점에서 분석하고, 서로의 의견을 검토한 다음, 최종적으로 모든 의견을 종합한 답변을 제공해 주세요."
```

어떤 느낌인지 바로 감이 오실겁니다. 저는 클로드에게 가상의 팀을 만들어달라고 요청하고, 그 가상의 팀이 서로의 의견을 분석 이나 피드백 후 최종 답변을 달라고 요구 했습니다.

클로드 프로젝트가 스스로 **==‘생각’할 수 밖에 없게끔 하는 구조==**이며, 1질문에 1답변을 받는 일반 질문들과 다르게, 여러가지의 답변을 한번에 받아보고, **==스스로 검토하게 하는 구조==**로써 훨씬 퀄리티 높은 답변을 받을 수 있습니다.

그럼 이 구조를 **==XML구조로 다시 다듬으면==** 이러한 형태가 됩니다.

    </member>

      <thinking_style>분석적, 회의적, 철저한 검토</thinking_style>
    </member>
    
    <member id="민지">
      <name>실행 전문가</name>
      <expertise>실용적 구현, 현실적 제약 고려, 액션 플랜 수립</expertise>
      <thinking_style>현실적, 절차적, 결과 지향적</thinking_style>
    </member>
  </team_members>
  
  <workflow>
    <round id="1">
      <name>초기 분석</name>
      <action>모든 팀원이 주제를 각자의 관점에서 분석하고 초기 견해를 제시합니다.</action>

    </round>
    
    <round id="3">
      <name>통합 및 정제</name>
      <action>팀원들의 의견을 통합하여 공통점과 차이점을 식별하고 핵심 인사이트를 추출합니다.</action>
    </round>
    
    <round id="4">
      <name>최종 합의</name>
      <action>모든 관점을 고려한 종합적인 해결책이나 답변을 도출합니다.</action>
    </round>
  </workflow>
  
  <output_format>
    <final_response>
      <summary>팀의 주요 발견점과 결론을 요약합니다.</summary>
      <key_insights>각 전문가가 기여한 핵심 통찰력을 통합합니다.</key_insights>
      <recommendation>종합적인 권장사항이나 해결책을 제시합니다.</recommendation>
    </final_response>
  </output_format>
</agent_team>

클로드는 보통 1개의 문제에 1개의 답변을 내놓기 마련인데, 이 방식을 이용하면 **==자신이 낸 의견에 정 반대되는 의견도 스스로 생각하게 하는게 이 프롬프트의 핵심==**입니다.
