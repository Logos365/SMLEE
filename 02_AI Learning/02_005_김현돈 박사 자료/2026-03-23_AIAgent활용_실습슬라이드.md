<div class="step-badge">Windows — PowerShell 관리자 권한으로 실행</div>

## STEP ①  Claude Code 설치

설치가 끝나면 **(새 터미널 창)**에서:

```powershell
npm install -g @anthropic-ai/claude-code
```

```powershell
$p = "$env:APPDATA\npm"
```

```bash
echo 'export ANTHROPIC_API_KEY="sk-ant-여기에키붙여넣기"' >> ~/.zshrc && source ~/.zshrc
```

```json
"enabledPlugins": {

  "report-generator@honeypot": true,
  "paper-style-generator@honeypot": true
```

## 📄 Report Generator

> **연구 노트를 기관 품질 보고서로 자동 변환**

What → Why → How → Impact **4단계 작성 패턴** 자동 적용

```text
/report-generator 이번 달 실험 결과를 연구보고서로 작성해줘
```

**도메인 자동 감지:**

| 입력 키워드 | 선택 프레임워크 |
|------------|----------------|
| ROS2, 로봇, 제어 | 로봇공학 전용 구조 |
| AI, 딥러닝, 모델 | AI/ML 전용 구조 |
| 나머지 | 범용 기관 보고서 |

- 최대 **9장** 자동 구성
- Gemini로 도식·이미지 자동 삽입

---

## 📋 ISD Generator

> **국가 연구 과제 계획서 5장 자동 생성**

```text
/isd-generator 나노메타물질 기반 초박형 렌즈 개발 과제 계획서 작성해줘
```

**생성 순서** (장 간 의존성 자동 고려):

```
3장 (연구개발 방법)  →  1장 (필요성)  →  2장 (목표)
         →  4장 (추진체계)  →  5장 (기대성과)
```

- Gemini로 **개념도·구성도 이미지 자동 생성**
- 장별 분량·양식 자동 준수

> 💡 초안 작성 시간 **수일 → 수 시간** 단축 목표

---

## 📝 HWPX Generator

> **HWP 문서를 AI로 생성·편집·분석**

```text
/hwpx-generator 이 마크다운 보고서를 HWP 파일로 변환해줘
```

```text
/hwpx-generator 연구비 정산 양식 템플릿에 이 데이터 채워줘
```

| 기능 | 설명 |
|------|------|
| MD → HWP | 마크다운을 HWP 템플릿으로 변환 |
| 이미지 삽입 | 표·그래프 자동 포함 |
| 내부 편집 | ZIP 구조 직접 수정 (안전한 내용 교체) |
| 분석 | 기존 HWP 문서 내용 요약·추출 |

> 💡 국내 행정 서류 표준 포맷 HWP를 코드 없이 다룸

## 🎓 Paper Style Generator

> **논문 PDF 분석 → 저자의 글쓰기 패턴 학습**
