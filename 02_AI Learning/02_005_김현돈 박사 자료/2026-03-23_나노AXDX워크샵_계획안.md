### B. 터미널과 친해지기 (쉘의 이해)

**쉘(Shell)이란?**: 사용자의 텍스트 명령을 컴퓨터(커널)가 이해하도록 통역해 주는 핵심 도구

**파워쉘(PowerShell) 특징 및 리눅스(Bash) 대비 장점**: 구형 명령 프롬프트(cmd)를 진화시킨 강력한 최신 쉘
- **객체(Object) 지향**: 데이터가 엑셀 표처럼 속성별로 관리되어 필터링/추출이 훨씬 쉬움
  - *[데모 꿀팁 1] 조건 탐색*: `ls | Where-Object Extension -eq ".csv"`
  - *[데모 꿀팁 2] 용량 정렬*: `ls | Sort-Object Length -Descending`
  - *[데모 꿀팁 3] 메모리 관리*: `Get-Process | Where-Object WorkingSet -gt 1GB`
- **명령어가 직관적임**: `Get-Process`, `New-Item` 등 [동사-명사] 규칙
- **윈도우 완벽 호환**: 파일, 시스템, 엑셀 등 외부 프로그램까지 직접 제어

**PowerShell 7.6.0 설치 권장 이유 (Claude Code 필수 요건)**
- **[이유 1] 화면 깨짐 방지**: 구형 `cmd`에서는 마크다운/이모지가 깨지지만 파워쉘에선 완벽 출력
- **[이유 2] AI 성능 100% 발휘**: 파워쉘 환경에서 객체 지향 기반 고급 코드를 짜내어 미션 성공률 극대화
- **[이유 3] 리눅스 호환**: AI가 `ls`, `rm` 등 리눅스 명령어를 내뱉어도 파워쉘이 자동 번역

### C. 왜 챗GPT 대신 Claude와 Gemini인가?

*(데이터 출처: [LMSYS Chatbot Arena](https://huggingface.co/spaces/lmsys/chatbot-arena-leaderboard) 리더보드)*

1. **Claude (코딩 1위)**: 코드 해석, 엑셀 처리, PC 직접 조작에서 압도적
2. **Gemini (정보 처리량 1위)**: PDF 수십 편을 한번에 분석 가능한 컨텍스트 창
3. **최강 시너지**: Gemini로 자료 분석 → Claude로 자동화 실행

### D. AI 코딩 도구 상세 비교

| 핵심 도구 | 구동 환경 | 최고 장점 | 한계점 | 연구원 추천도 |
|:---:|:---|:---|:---|:---:|
| **Cursor** | 전용 에디터 (IDE 설치) | 예측 코딩의 끝판왕 | 무겁고 사용법 학습 필요 | 낮음 (개발자용) |
| **Antigravity** | VS Code 연동 | 시스템 구축/버그 해결에 강함 | 연구실 잡무용으론 무거움 | 보통 |
| **Claude Code** | 터미널 (PowerShell) | 프롬프트 한 줄로 PC 제어 | 까만 창에 대한 심리적 장벽 | **매우 추천** |

### E. 기초 환경이 필요한 이유
- **Node.js**: Claude Code의 실행 엔진. 비동기 처리 속도가 Python보다 뛰어남
- **Git**: AI 실수 시 즉시 롤백 가능한 안전망. 미설치 시 복구 불가 경고 발생

### F. 설치 실습 (상세 가이드)

#### 1단계: 필수 환경 3종 세팅
```powershell
"Microsoft.PowerShell", "Git.Git", "OpenJS.NodeJS.LTS" | ForEach-Object { winget install --id $_ --source winget }
```
*(기존 앱 업데이트: `winget upgrade --all`)*

![winget 설치 화면](attachments/winget.png)

#### 2단계: Claude Code 본체 설치
새로 설치된 **PowerShell 7**을 열고:
```powershell
npm install -g @anthropic-ai/claude-code
```
- `npm`: Node.js 앱스토어 / `install`: 설치 / `-g`: 시스템 전체에서 사용 가능하게

#### 3단계: 플러그인 장착
`claude`를 실행한 뒤 챗봇 창에서 **아래 두 가지 방법 중 하나**로 설치합니다:

**[방법 A] 대화형 마켓플레이스 탐색 (권장)**
1. `/plugin` 입력 후 엔터
2. 방향키로 **Marketplace** 탭 이동 후 **[Browse]** 선택
3. `oh-my-claudecode` 및 `honeypot` 등 원하는 에이전트 찾아 **<Install>** 선택

**[방법 B] 다이렉트 커맨드 입력 (빠른 설치)**
플러그인 이름을 안다면, 긴 주소 필요 없이 이름만 쳐서 바로 설치할 수 있습니다:
```text
/plugin install oh-my-claudecode
/plugin install honeypot
```

#### 초스피드 원라이너 (1~3단계를 한 번에! 🚀)
위 과정을 하나하나 따라가기 번거롭다면 아래 코드로 한 번에 완료합니다. (※ 단, Honeypot 등의 추가 에이전트는 향후 별도로 마켓플레이스에서 장착해야 합니다.)
```powershell
"Microsoft.PowerShell", "Git.Git", "OpenJS.NodeJS.LTS" | ForEach-Object { winget install --id $_ --source winget }; npm install -g @anthropic-ai/claude-code oh-my-claude-code
```

### J. 마켓플레이스 방식 비교: 로컬 vs Git

|       | 로컬 디렉토리                                   | Git 원격                                           |
| ----- | ----------------------------------------- | ------------------------------------------------ |
| 등록 명령 | `/plugin marketplace add /path/to/folder` | `/plugin marketplace add https://github.com/...` |
| 업데이트  | `git pull` 직접 실행                          | `/plugin` → `u`로 자동 업데이트                         |
| 코드 수정 | 직접 편집 가능 (개발자용)                           | 읽기 전용 (캐시 복사본)                                   |
| 오프라인  | 동작함                                       | 최초 설치 시 인터넷 필요                                   |
| 다른 PC | 같은 경로에 클론 필요                              | settings.json만 복사하면 됨                            |

- **워크샵 참석자**: Git 방식 추천 (자동 업데이트, 간편)
- **플러그인 개발자**: 로컬 방식 추천 (직접 편집 가능)

### K. OMC vs OMO 비교
- **OMC (클로드 특화형)**: Claude Code 성능을 200% 쥐어짜는 **최적화 레이어**
- **OMO (범용 개방형)**: 어떤 AI든 갈아끼울 수 있는 **독립 확장형 에이전트**
- 한 줄 요약: OMC = "클로드 깎는 특화 장인", OMO = "어떤 AI든 고용하는 용병단 본부"
