# ✅ 1️⃣ 먼저 “이미 git 연결된 폴더인지” 확인

PowerShell에서:

cd "D:\Obsidian\SMLEE_D drive in Office PC"  
git status

---

## 🔎 결과에 따라 갈림

### 🟢 경우 A — 정상적으로 git repo라면

`On branch main` 이런 메시지가 나오면  
이미 GitHub와 연결된 상태입니다.

그럼 그냥 이 3줄이면 끝:

git add .  
git commit -m "Update from office PC"  
git push origin main

---

### 🔴 경우 B — 이런 에러가 나오면

fatal: not a git repository

그럼 GitHub와 아직 연결이 안 된 상태입니다.

아래 순서대로 한 번만 설정하면 됩니다.

# ✅ 2️⃣ GitHub repo와 처음 연결하는 경우

⚠️ 반드시 폴더 안에서 실행하세요:

cd "D:\Obsidian\SMLEE_D drive in Office PC"

---

## ① Git 초기화

git init

---

## ② 원격 저장소 연결

git remote add origin https://github.com/Logos365/SMLEE.git

---

## ③ 기본 브랜치 main 설정

git branch -M main

---

## ④ GitHub에 이미 파일이 있다면 (중요)

GitHub에 README 같은 파일이 이미 있다면:

git pull origin main --allow-unrelated-histories

(충돌 나오면 알려주세요)

---

## ⑤ 파일 추가 & 업로드

git add .  
git commit -m "Initial sync from office PC"  
git push -u origin main

---

# 🔁 이후 반복 루틴 (앞으로 계속 사용할 것)

로컬에서 수정 후:

git add .  
git commit -m "Update notes"  
git push

다른 컴퓨터에서 최신 가져올 때:

git pull
