# 나노필름 박리 특허 초안 검토의견 — 소재·메커니즘 관점

- 작성자: 이승모 (2차원 박막 박리·전사 연구)
- 대상: 김찬 박사 공유 명세서 2건
  - **출원 1**: 박리 보조 유체를 이용하여 나노필름을 기판에서 안정적으로 박리하는 방법 및 장치
  - **출원 2**: 박리 과정의 균열 및 유체 거동을 관찰하고, 박리속도·유체공급량 등을 제어하는 방법 및 장치
- 목적: 변리사 미팅(9/1) 반영용. 소재 관점·메커니즘 관점에서 초안에 더할 의견, 추가/수정 제안 정리

---

## 0. 핵심 요약 (먼저 볼 5가지)

1. **두 초안 모두 "유체를 목표계면으로 선택 유도"라는 아이디어는 좋으나, 그 선택성을 만드는 물리·소재 파라미터가 청구항·명세서에 거의 특정되어 있지 않다.** 젖음 대비(wettability contrast) 하나에만 의존하고 있어, water-assisted / bubble-free transfer 계열 선행기술 대비 진보성 논거가 약하다. → **유체 물성(표면장력·점도·pH·이온종), 젖음 대비의 정량 창, 전사필름 강성·박리각**을 종속항·실시예로 보강 권장.

2. **메커니즘 서술이 "모세관력·라플라스 압력·메니스커스" 수준에서 멈춰 있다.** 박리를 **계면 파괴(에너지 방출률 G vs 계면 접착일 Γ)** 로 기술하고, 유체의 역할을 (a) 계면 접착일 저하, (b) 균열 선단 쐐기/흡인 압력, (c) 재접착(히스테리시스) 억제로 분해해 서술하면 제어 파라미터의 근거가 명확해지고 권리범위가 넓어진다.

3. **출원 2의 제어 대상을 "계면 균열 선단(C)과 액체 전선(L)의 상대 거동"으로 명확히 물리 모델화**하면(예: C–L 간격 δ를 탄성모세관 길이·모세관수의 함수로 목표값 설정) 단순 피드백 특허를 넘어선 차별성이 생긴다.

4. **"이 방법을 어떻게 특화할 것인가"**: ① 소재정합형 유체 처방(필름–기판 조합별 조성 룩업), ② 젖음 대비 정량 공정창, ③ 선단 동기화(front-locking) 제어, ④ 무차원(모세관수) 기반 제어, ⑤ **기체상/노점 제어 무잔류 박리**, ⑥ 국소 자극 병용(가열/메가소닉/저전위), ⑦ 패턴·선택영역 박리, ⑧ 대면적·롤투롤 폭방향 프로파일 제어. 이 중 ⑤와 ②는 명세서에 이미 실마리가 있어 즉시 강화 가능.

5. **절차적 이슈**: 두 출원의 발명의 명칭이 동일하고 부호·도면 체계가 상충한다. 자기충돌(이중특허) 및 상호 종속성(출원 1이 축소되면 출원 2 기반도 흔들림)을 변리사와 정리 필요. 실시예 데이터가 전무하므로 국내우선권 12개월 내 데이터 보강 계획을 세울 것.

## 1. 전반적 코멘트

### 1.1 강점 (유지·강조할 부분)

| 항목 | 평가 |
|---|---|
| 유체를 "국소 수용 공간(오버행 구조)"에 담아두는 구성 | 유체 사용량·측방 확산을 줄이는 실질적 아이디어. 침지식 water transfer 대비 차별점이 될 수 있음 |
| 젖음 대비로 목표/비목표 계면 선택 | 핵심 사상. 다만 정량화 필요(§2, §4.2) |
| 박리 후 유체가 기판 측 잔류 → 필름/전사필름 무건조 연속 전사 | 공정 통합 관점에서 강한 세일즈 포인트. 효과항으로만 있고 청구되지 않음 → 방법항으로 끌어올릴 것 |
| 동적 접촉각(전진/후퇴)을 젖음 지표로 규정 | 이동 접촉선 문제를 정적 접촉각으로만 보지 않은 점 良. §2.3에서 히스테리시스 조건으로 더 강화 가능 |
| 출원 2에서 C·L을 동시 관찰하고 상대 거동을 제어 | 방향성은 정확. 물리 모델·제어 출력 다양화로 차별성 확보 필요(§3.2, §4.3) |
| 기체상 유체가 계면에서 응축하여 박리 보조 | 무잔류·초청정 박리로 특화 가능한 강력한 축인데 한 문장으로만 언급됨(§4.5) |

### 1.2 공통 보완 필요 사항

- **유체 = 물성 미특정**: "극성 액체 / 수계 / 알코올계 / 계면활성제 포함 수계 / 탈이온수" 수준. 소재적으로는 표면장력, 점도, 증기압/노점, pH, 이온종·농도, 계면활성제 종류/CMC, 첨가제(부식방지·산화방지)가 모두 박리 선택성과 기판 재사용성에 직접 영향. 이 중 무엇도 청구·한정되어 있지 않음.
- **전사필름 = "고분자 필름"만**: 굽힘 강성(EI), 두께, 탄성계수, 점탄성, 광투과성(출원 2 관찰용)이 박리 에너지·박리각·선단 안정성을 지배하는데 서술 없음.
- **메커니즘 = 파괴역학 프레임 부재**: G와 Γ의 비교, 속도 의존성, 선단 불안정성이 빠져 있어 "왜 이 파라미터를 제어하면 되는가"의 근거가 약함.
- **정성적 표현 다수**("국소량", "소량", "잠기지 않는", "기 설정된 범위") → 명확성(기재불비) 리스크. 정의절·정량 예시 보강.
- **실시예 데이터 0건** → 한국 등록은 가능하나 진보성 방어·해외(미국/EP) 대응·무효심판에서 취약.
- **선행문헌 1건만 인용** (공개 10-2017-0123448). water-assisted transfer, bubble-free/electrochemical delamination, capillary/clean transfer 계열 문헌군 대비 서술이 필요.

## 2. 소재 관점 보완 제안

### 2.1 박리 보조 유체 (가장 시급)

명세서·종속항에 아래 파라미터의 **범위와 근거**를 추가 권장. 각 항목은 독립적으로 종속항화 가능.

| 파라미터 | 제안 취지 | 예시 한정(수치는 실험으로 확정) |
|---|---|---|
| 표면장력 γ | 모세관 침투 구동력·라플라스 압력 결정. 낮으면 비목표계면까지 침투, 높으면 선단 미도달 | 예: 20–73 mN/m, 바람직하게는 25–50 mN/m |
| 점도 μ | Lucas–Washburn 침투속도 ∝ γ/μ. 박리속도와 정합 필요(§3.2) | 예: 0.5–20 mPa·s |
| 증기압 / 노점 | 잔류 유체 자연 건조성 ↔ 선단 부근 증발로 인한 건식 박리 위험의 균형. 무잔류 전사 설계(§4.5)의 핵심 | 노점/기판온도 상대값으로 규정 |
| pH | 그래핀·기판(SiO₂) 계면 제타전위·전기이중층 반발, SiO₂ 계면 Si–O 결합 가수분해 촉진(응력부식, §3.4) | 예: pH 8–12 (알칼리) 또는 pH 2–4 옵션 |
| 이온종·농도 | OH⁻, F⁻ 등은 산화물 계면 화학적 약화, 알칼리 양이온은 전기이중층 조절. 단 기판 오염/필름 도핑 주의 | 종속항으로 "OH⁻ 또는 F⁻ 함유", 농도 mM 수준 |
| 계면활성제 | 동적 표면장력 저하로 이동 접촉선 pinning 완화. 이온성/비이온성 구분, CMC 이하/이상 | 비이온성 계면활성제 CMC의 0.1–2배 |
| 용존 가스 / 탄산 | 계면 미세기포로 박리 보조(장점) ↔ 필름 손상·비균일(단점). 옵션·배제 양쪽 청구 가능 | "용존 가스량 ≤ X" (무기포) 또는 "CO₂ 포화" (기포 보조) |
| 첨가제 | 부식방지제(기판 반복 재사용 시 표면 열화 억제), 산화방지제/환원제(그래핀 산화·p-도핑 억제) | 종속항 |
| 온도 | γ·μ·증기압·계면 화학반응 속도 동시 제어. 가열/냉각 실시예 | 유체 또는 기판 5–80 °C |

**메커니즘 연결 문안 예시 (명세서 삽입용)**
> 박리 보조 유체는 목표계면의 유효 접착일(work of adhesion)을 저하시키는 화학적 작용과, 계면 균열 선단 부근에서 모세관력·라플라스 압력에 의해 균열면을 이격시키는 역학적 작용을 겸한다. 유체의 표면장력, 점도, pH 및 이온 조성은 상기 두 작용의 상대적 기여를 조절하는 인자로서, 목표계면에 대한 유효 접착일 저하량이 비목표계면에 대한 저하량보다 크도록 선택된다.

### 2.2 전사 필름

- 구체 소재 열거: PMMA, PDMS, thermal release tape(TRT), PVA, PC, EVA, COP, UV/열 박리형 점착 테이프, 무기/복합 전사 스택(상위 개념: "나노필름과의 점착력을 가지는 전사층 및 이를 지지하는 캐리어층을 포함하는 전사 구조체").
- **스위처블 점착**: 박리 시에는 필름–전사필름 점착일 > 유체의 목표계면 침투 구동력(비목표계면 점착 유지), 전사 시에는 열/UV/기계적 트리거로 타겟기판에 릴리스. 종속항으로.
- **젖음 특성을 기판보다 낮게 만드는 구체 수단**: 표면 불소화, 실리콘 이형층 코팅, 저에너지 플라즈마 처리, 나노텍스처(초발수). "지지부의 낮은 젖음 특성" 문단(도 4 관련)에 준하는 서술을 전사필름에도 병기.
- **역학 파라미터(중요)**: 두께, 탄성계수, 굽힘 강성 B(=Et³/12(1–ν²)), 점탄성(속도 의존 박리). 박리각·롤 곡률반경과 함께 종속항. 메커니즘상 에너지 방출률 G를 좌우하는 지배 변수(§3.1).
- **출원 2용**: 광투과성(관찰 파장대 투과, 낮은 자가형광), 가스 투과성(유체 증발 경로).

### 2.3 지지부

- 표면에너지 수치 범위, 표면 거칠기(Wenzel/Cassie 상태 명시), 마이크로/나노 구조에 의한 초발수.
- **동적 접촉각 히스테리시스 조건**으로 젖음 대비를 규정: "지지부·전사필름 표면에서 박리 보조 유체의 접촉각 히스테리시스가 X° 이하이고, 후퇴 접촉각이 Y° 이상" → 유체가 표면에서 뭉치지 않고 유체 수용 공간에 유지되며, 선단 이동 시 pinning으로 인한 불연속 유도가 방지됨. (정적 접촉각만으로는 이동 접촉선 거동을 규정하지 못함.)
- 열전도도(온도 제어 실시예), 대전 방지(2D 필름 ESD 손상 방지), 화학적 내구성(반복 사용).

### 2.4 기판 및 2D 필름

- **기판 표면 처리로 젖음성·계면 접착에너지 조절**: O₂ 플라즈마, UV-오존, 자기조립단분자막(HMDS, OTS, APTES), 계면 이형층. → 목표계면 젖음성을 의도적으로 높여 유체 선택성을 강화하는 실시예.
- **기판 표면의 젖음 패터닝**: 친수 채널로 유체를 특정 경로/형상으로 유도(§4.7), 박리 시작점 정의.
- 성장 기판 표면 형상(스텝·테라스)·결정방위에 따른 균열 선단 진행 이방성 → 관찰·제어 대상(출원 2와 연결).
- **2D 필름 소재별 계면 접착에너지 차이 명시** (유체 침투 구동력 대비의 기준):
  - 참고 문헌값 예시: 그래핀/SiO₂ ~0.3–0.45 J/m², 그래핀/Cu ~0.7 J/m², h-BN·TMD는 조합별 상이. (수치는 "예시"로만, 실측 권장.)
  - 필름 종류(그래핀=소수성 경향, MoS₂/WS₂, h-BN)와 기판(SiO₂=친수, 사파이어)에 따라 목표계면 젖음 대비가 달라지므로, **유체 조성을 필름–기판 조합에 정합**시킨다는 서술(§4.1).
- 필름의 결정립 크기·결함밀도·도메인 경계 → 균열 선단이 결함부에서 편향·정지·분기 → 출원 2의 이상상태 검출 항목에 명시.
- 필름 두께(단층/다층)·적층수 → 굽힘 강성·파단 변형률. 그래핀 파단 변형률은 결함부에서 크게 낮아짐 → 국부 응력집중 관리가 박리 품질을 좌우.

### 2.5 요약: 추가 권장 종속항 (소재)

1. 유체의 표면장력이 25–50 mN/m인 것
2. 유체의 점도가 0.5–20 mPa·s인 것
3. 유체가 pH 8–12의 알칼리성 수계 액체이거나, OH⁻ 또는 F⁻를 함유하는 것
4. 유체가 비이온성 계면활성제를 CMC의 0.1–2배로 함유하는 것
5. 유체가 부식방지제 또는 산화방지제를 더 포함하는 것
6. 전사필름이 PMMA, PDMS, TRT, PVA, COP 중 하나이거나, 점착층과 캐리어층을 포함하는 전사 구조체인 것
7. 전사필름의 굽힘 강성 또는 두께가 기판 크기·박리각에 따라 설정되는 것
8. 지지부·전사필름 표면에서 유체의 접촉각 히스테리시스가 X° 이하인 것
9. 기판 표면이 플라즈마 처리 또는 SAM 처리되어 목표계면 젖음성이 조절된 것
10. 유체 또는 기판의 온도가 5–80 °C 범위에서 조절되는 것

## 3. 메커니즘 관점 보완 제안

### 3.1 파괴역학(계면 파괴) 프레임 도입

현재 명세서는 박리를 "점착력 약화 → 분리"로만 설명한다. 아래 프레임을 추가하면 제어 파라미터의 근거가 생기고 청구범위가 넓어진다.

- 박리 진행 조건: **에너지 방출률 G ≥ 유효 계면 접착일 Γ_eff**
- 유체의 역할을 3가지로 분해:
  1. **Γ_eff 저하**: 유체가 계면에 침투해 van der Waals·수소결합 상호작용을 스크리닝하고(습윤 시 Γ_wet < Γ_dry), 산화물 계면에서는 화학적 결합을 가수분해(§3.4).
  2. **G에 기여하는 쐐기/흡인 압력**: 균열 선단 부근 좁은 간극에서 메니스커스가 형성하는 라플라스(음)압이 균열면을 이격시키는 방향으로 작용(elastocapillary wedge).
  3. **재접착(adhesion hysteresis) 억제**: 유체 막이 박리된 면의 즉시 재접착·냉접착을 방지.
- G의 지배 변수: **전사필름 장력 T, 박리각 θ, 전사필름 굽힘 강성 B, 박리속도 v** (Kendall peel: G ≈ (T/b)(1−cosθ) + 굽힘 항). → 이 변수들을 종속항·제어 출력으로 명시(§4.9).
- 목표/비목표계면의 선택성을 **"목표계면에서의 (G − Γ_eff)가 비목표계면에서의 (G − Γ_eff)보다 크다"** 로 일반화하면, 젖음 대비뿐 아니라 화학적·역학적 수단 모두를 포섭.

### 3.2 모세관 침투 vs 균열 진행의 경쟁 (출원 2의 물리적 핵심)

- 모세관 침투 특성길이: L² ≈ (γ r cosθ / 2μ) · t (Lucas–Washburn). 균열 선단이 이 침투 프론트보다 **빠르면** 선단 부근이 마르며 "건식 박리" → 필름 손상(출원 2가 이미 언급). **느리면** 유체가 비목표계면·측방으로 과침투.
- 따라서 출원 2의 제어량인 **C–L 간격 δ 및 상대속도 Δv**는 위 경쟁의 직접 관측량이다. 이를 명세서에 물리적으로 서술하면 "왜 δ를 일정 범위로 유지하면 되는가"가 자명해진다.
- **무차원 정리 권장**: 모세관수 Ca = μv/γ. Ca가 임계값 이하이면 안정한 직선 선단, 초과하면 손가락형 침투(§3.5). 제어부가 Ca(또는 그 추정치)를 공정창 내로 유지하도록 규정하면 소재·스케일이 바뀌어도 성립하는 청구항이 됨(§4.4).

### 3.3 탄성모세관(elastocapillary) 상호작용

- 얇은 전사필름 + 유체 메니스커스 → 탄성모세관 길이 ℓ_ec ≈ (B/γ)^{1/3}. 메니스커스가 이 스케일에서 필름을 국부적으로 변형시켜 균열 선단 개구(開口) 형상과 라플라스 압력을 결정.
- 목표 δ*(C–L 간격 목표값)를 **ℓ_ec, Ca, 계면 접착일의 함수**로 설정한다는 서술을 추가하면 출원 2의 "기 설정된 범위"에 물리적 정의가 부여됨(기재불비 리스크 완화).

### 3.4 화학적 계면 약화 (응력부식균열)

- 물 분자의 산화물 계면 침투는 SiO₂에서 Si–O–Si + H₂O → 2 Si–OH 반응을 균열 선단 응력장 하에서 촉진(subcritical crack growth, Wiederhorn Region I/II/III). 즉 유체는 윤활·쐐기뿐 아니라 **속도 의존적 화학적 균열 성장제**로 작용.
- 이를 명시하면 (a) pH·이온종 종속항의 근거가 되고, (b) "박리속도–유체" 제어가 화학반응 속도 정합이라는 새로운 논거가 생긴다.
- 주의: 필름·기판에 화학층 잔류 가능 → 기판 재사용 종속항(§4.10)과 세트로.

### 3.5 선단 불안정성 (명세서·출원 2 이상상태에 추가)

| 불안정 모드 | 원인 | 결과 | 관찰 지표 |
|---|---|---|---|
| 손가락형 침투(fingering) | Ca 과대, 젖음 대비 부족, 점도 정합 실패 | 국부 응력집중 → 필름 찢김 | 선단 형상의 파형/분기, 명암 경계 요철 |
| Stick–slip | 접착 히스테리시스, 박리속도 과대, pinning | 선단 튐 → 균열 급진전, 주름 | C 속도의 주기적 변동, 음향 버스트, 하중 톱니파 |
| L이 C를 추월 | 유체 공급 과다, 박리속도 과소 | 비목표계면 침투, 측방 확산 | δ 부호 반전 |
| 건식 박리 구간 | 유체 공급 과소, 증발 과다, 박리속도 과대 | 필름 크랙·전사율 저하 | 선단 부근 메니스커스 소실 |
| 선단 정지/피닝 | 결정립계·결함·기판 스텝 | 국부 잔류응력, 전사 불량 | C 속도 0 구간, 특정 위치 반복 정지 |

→ 출원 2 청구항의 "이상 상태"를 위 5종으로 구체 열거하고, 각각에 대응하는 제어 동작(공급량↓/흡입량↑, 박리속도↓, 가압력 조절, 장력·박리각 조절, 국소 자극 인가)을 매핑.

### 3.6 명세서 삽입용 메커니즘 단락 (초안)

> 나노필름의 박리는 나노필름과 기판 사이 계면에서의 계면 파괴로 이해될 수 있으며, 계면 균열 선단에 작용하는 에너지 방출률이 해당 계면의 유효 접착일 이상일 때 균열이 진전한다. 박리 보조 유체는 (i) 계면에 침투하여 상기 유효 접착일을 저하시키고, (ii) 계면 균열 선단 부근의 좁은 간극에서 표면장력에 의해 형성되는 곡면 계면(메니스커스)의 라플라스 압력을 통해 균열면을 이격시키는 방향의 힘을 부가하며, (iii) 박리된 면의 재접착을 억제한다. 상기 (i)의 기여는 유체의 극성·이온 조성 및 pH에, 상기 (ii)의 기여는 유체의 표면장력, 점도, 전사 필름의 굽힘 강성 및 박리 속도에 의존한다. 계면 균열 선단의 이동 속도가 유체의 모세관 침투 속도보다 빠르면 계면 균열 선단 부근에서 유체가 고갈되어 나노필름이 건식으로 박리되고, 반대로 느리면 유체가 비목표계면 또는 측방으로 과도하게 침투한다. 따라서 액체 전선과 계면 균열 선단 사이의 간격 및 상대 이동 속도를 소정 범위 내로 유지하도록 박리 속도 및 유체 공급량을 조절함으로써, 나노필름의 손상 없이 균일한 박리가 이루어진다.

## 4. 이 방법을 어떻게 "특화"할 것인가 (차별화 포인트)

> 아래는 명세서에 실시예/종속항으로 추가하거나, 필요 시 별도 분할·후속 출원으로 가져갈 후보. ★ = 초안에 이미 실마리가 있어 즉시 강화 가능.

### 4.1 소재정합형 유체 처방 (materials-matched fluid) ★부분

- 필름–기판 조합별(그래핀/Cu, 그래핀/SiO₂, MoS₂/사파이어, h-BN/Ni 등)로 목표계면 접착일·표면화학이 다르므로, **각 조합에 대해 표면장력·pH·이온종·계면활성제를 매칭한 유체 조성표**를 실시예로 제시.
- 청구: "목표계면의 유효 접착일 저하량이 비목표계면의 저하량보다 큰 조성"이라는 기능적 한정 + 조성 예시 다발.

### 4.2 젖음 대비의 정량적 공정창 ★

- 현재 "낮게 마련" → **"지지부·전사필름에 대한 유체의 후퇴 접촉각 ≥ θ₁, 기판에 대한 전진 접촉각 ≤ θ₂, 또한 θ₁ − θ₂ ≥ Δθ*"** 형태로 창을 규정.
- 또는 유효 접착일 기준: Γ_target,wet ≤ αΓ_target,dry 이면서 Γ_nontarget,wet ≥ βΓ_nontarget,dry.
- 이 "창"이 방어의 핵심(선행기술은 통상 조건을 특정하지 않음).

### 4.3 선단 동기화(front-locking) 제어 — 출원 2의 브랜딩

- C와 L의 **위상 잠금**: δ(C–L 간격)를 목표값 δ*로 유지하도록 박리속도 v와 공급유량 Q를 **동시(MIMO)** 제어. δ*는 §3.3의 ℓ_ec·Ca·접착일로 결정.
- 단순 "간격을 범위 내 유지"보다 진일보: **δ*를 필름 종류·두께에 따라 in-situ로 갱신**(적응 제어)하는 종속항.

### 4.4 무차원(모세관수) 기반 제어

- 제어부가 μ, γ, v로부터 Ca를 추정하고 Ca를 안정 창 [Ca_min, Ca_max] 내로 유지. 소재·장비 스케일이 바뀌어도 성립하는 상위 청구항.
- 병행: 접착일 대비 무차원수(예: G/Γ)를 1보다 약간 큰 값으로 유지하는 "최소 침습 박리".

### 4.5 기체상 / 노점 제어 무잔류 박리 ★

- 액체 대신 **포화 증기를 계면에서만 응축**시켜 박리 후 즉시 재증발 → 필름·전사필름·기판에 잔류물 0에 가깝게.
- **삼각 제어**: 분위기 습도(또는 증기 분압) – 기판 온도 – 박리속도. 노점 대비 기판 표면온도 차로 응축량 조절.
- 초청정·건조 불필요 → 반도체 팹(BEOL) 친화. **강한 독립 세일즈 포인트**이므로 별도 절/도면 권장. 유기 증기(알코올) 옵션도.

### 4.6 국소 자극 병용 (field-assisted capillary delamination)

- 균열 선단에만 국소적으로 인가: 가열/냉각, 메가소닉/초음파, 저전위 전기화학(전해질 유체 + 수 V 이하로 계면 제타전위·미세 반발 제어, 단 기포 발생은 억제), UV.
- 각 자극을 종속항. "유체 + 자극" 조합이 접착일을 **시공간 선택적**으로 낮춘다는 서술.

### 4.7 패턴 전사 / 선택 영역 박리

- 기판 또는 지지부에 젖음 패턴(친수 채널/소수 댐)을 두어 유체를 원하는 형상으로 유도 → 필름을 특정 형상만 박리·분할 전사(소자 어레이 피치에 맞춤).
- 도 5의 가이드(212)를 "젖음 패턴 가이드"로 일반화.

### 4.8 대면적 · 롤투롤 확장

- 벨트형 가압부 + 라인 유체 공급 + **라인스캔 카메라/간섭계로 폭방향 C·L 프로파일** 관찰.
- 폭방향 불균일(중앙 처짐, 엣지 선행, 스큐) 보정: 다점 유체 공급·다점 장력·존별 박리속도.
- 상용화 관건이 대면적 균일성이므로 실시예로 반드시 포함 권장.

### 4.9 전사필름 장력·박리각 능동 제어

- 하중센서(출원 2에 이미 언급)로 G를 실시간 추정 → **장력 T·박리각 θ·롤 곡률반경**을 폐루프 제어해 G를 Γ_eff 바로 위로 유지.
- 제어 출력 목록에 T, θ, 곡률반경, 기판·유체 온도, 분위기 습도를 추가(현재는 박리속도·공급량·흡입량·가압력만).

### 4.10 기판 재사용 특화

- 유체가 기판 측 잔류 → 표면 화학층/유기물 잔류 가능. **"재사용 N회까지 목표계면 접착에너지 편차 ≤ ε"**, 인라인 기판 재생 모듈(플라즈마/린스/베이크)을 장치항에 추가.
- 재사용 경제성이 에칭 방식 대비 핵심 우위이므로 수치적 근거(잔류량·재사용 횟수) 실시예 권장.

## 5. 출원 1 상세 코멘트 (청구항 / 권리범위)

- **청구항 1(독립항)에 유체 물성·구조 한정이 전혀 없음.** "유체가 유체 수용 공간에 수용된 후 계면으로 유도"만으로는 water-assisted/capillary transfer 선행기술과 구별이 어려울 수 있음.
  - 옵션 A(넓게): 독립항은 현행 유지, 청구항 2(젖음 대비)·오버행 구조를 강한 종속항 군으로 다층 방어. 해외 진입 시 병합.
  - 옵션 B(안전): 독립항에 "지지부 및 전사필름의 젖음 특성이 기판보다 낮게 마련되어 유체가 유체 수용 공간에 국소 수용" 또는 "오버행 구조"를 포함.
  - → 변리사와 선행조사 결과 보고 결정.
- **청구항 2가 사실상 발명의 핵심인데 종속항.** 미국/PCT 대응 시 독립항화 검토.
- 청구항 5(침투속도 차이)는 **결과적·정성적 한정** → "젖음 대비 + 비목표계면 점착 밀착"이라는 원인을 함께 기재해 뒷받침 강화.
- 청구항 6(기체상)은 응축 메커니즘 설명은 있으나 조성·분압·노점 종속항이 없음 → §4.5로 확장.
- **장치항(17~)에 제어부 없음** → 출원 2와의 경계는 명확해지나, 출원 1 장치가 최소한의 조건(공급량 정량, 상대이동 속도) 제어를 포함하는 종속항은 두는 것이 실무상 유리.
- "국소량", "잠기지 않는" → 정량 예시("유체 부피가 유체 수용 공간 부피의 X% 이하", "유체 막 두께가 나노필름–전사필름 스택 두께 이하") 명세서 보강.
- 전사필름 "고분자 필름" → 상위 개념화(§2.2).
- 가압부: 박리각·곡률반경·장력 제어 요소를 종속항 추가(§3.1, §4.9).
- 효과항의 "박리 후 유체가 기판 측에 주로 잔류" → 방법 청구항으로 "박리 후 유체의 대부분이 기판 측에 잔류하여 나노필름·전사필름의 건조공정 없이 전사단계가 연속 수행"을 명시.

## 6. 출원 2 상세 코멘트 (청구항 / 권리범위)

- 독립항이 출원 1 없이도 성립하도록 작성된 점은 良. 다만 "박리 보조 유체 / 액체 전선 / 계면 균열 선단"을 전제하므로 **출원 1 계열에 사실상 종속**. 출원 1이 거절·축소되면 기반이 흔들림 → 두 명세서의 상호 인용·우선권 연계 명확화.
- **관찰 대상 C·L "둘 다" 필수** → (a) C만 또는 L만 직접 관찰하고 나머지는 모델·공급이력으로 추정하는 실시예, (b) C–L 간격 대신 L의 곡률·메니스커스 형상, 선단 부근 명암 구배를 대체 관측량으로 하는 실시예를 종속·대체항으로.
- **"기 설정된 범위"의 정의 부재** → §3.3의 물리 모델(ℓ_ec, Ca, 접착일)로 범위 결정 방법을 기재. 또는 "필름 종류별 캘리브레이션 테이블", "초기 구간 자기학습으로 범위 결정" 종속항.
- 센서 열거는 풍부하나 **신호 → C/L 위치 환산 알고리즘 구체성 부족**: 영상 엣지검출, 간섭무늬 카운팅, 편광 대비, 하중·토크 특징량, 음향 이벤트 검출 등 구체화 → SW 구현 뒷받침 및 회피설계 차단.
- **이상 상태를 5종으로 구체 열거**(§3.5 표) + 각 이상에 대응하는 제어 동작 매핑.
- **제어 출력 확장**: 현재 박리속도·공급량·흡입량·가압력 → 전사필름 장력, 박리각, 롤 곡률반경, 기판·유체 온도, 분위기 습도/증기 분압 추가(§4.9).
- **학습 기반 제어 강화**: 학습 데이터(관찰 영상 – 전사 품질), 보상함수(전사율·주름·잔류응력·선단속도 균일도), 필름 종류 간 전이학습, 디지털 트윈/MPC용 대리모델. AI 특허로서 가치 → 별도 후속 출원 후보.
- **폭방향(대면적) 제어**: 라인 센서로 폭방향 C·L 프로파일을 관찰, 존별 제어(§4.8) 종속항.
- **공정 데이터 로깅/트레이서빌리티**: 관찰 결과를 웨이퍼/롤 단위 품질 이력으로 기록, 규격 이탈 시 자동 정지·리워크 → 팹 채택 매력.
- 발명의 명칭을 "나노필름 박리 공정의 모니터링 및 제어 방법·장치" 등으로 차별화(§7).

## 7. 출원 1·2 관계 및 절차 이슈

1. **발명의 명칭이 동일**("나노 필름 박리방법 및 나노 필름 박리장치"). 심사관의 자기충돌·이중특허 지적 소지. 출원 2 명칭을 모니터링·제어 중심으로 변경.
2. **부호·도면 체계 상충**: 출원 1은 지지부=110, 출원 2는 박리부=110·지지부=111. 도면 번호도 각각 도1~7 / 도1~5. 두 건을 함께 읽는 심사·소송 국면에서 혼동. 통합 검토 시 정합.
3. **전략 옵션**: (a) 두 건 각자 출원 후 하나를 기초로 국내우선권(12개월) 주장하며 데이터·청구항 보강, (b) 한 건으로 통합 출원 후 분할, (c) 현행대로 병행하되 상호 인용 명시. → 변리사 판단.
4. **선행문헌 보강**: 공개 10-2017-0123448 외에 water-assisted transfer, bubble-free/electrochemical delamination, capillary peeling, clean transfer of 2D materials 계열을 배경기술에서 대비하고, 본원의 진보성 논거("유체의 국소 수용 후 선단 동반 유도" + "C·L 관찰 피드백" + "무건조 연속 전사")를 명확히 대치.
5. **해외 출원 계획**: 2D 소재 팹·장비 수요국(미국, 대만, 중국, 일본, EP) 진입 여부에 따라 독립항 전략(§5)과 데이터 요구 수준이 달라짐.
