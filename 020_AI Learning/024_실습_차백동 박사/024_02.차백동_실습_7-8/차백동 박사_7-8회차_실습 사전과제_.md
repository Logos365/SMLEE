app.py를 다음과 같이 완전히 수정해줘:

1. SerpAPI를 사용해서 Google Scholar 데이터 가져오기
2. 사이드바에 SerpAPI Key 입력창 추가
3. Google Scholar URL에서 user ID 자동 추출
4. 기존 기능 모두 유지 (키워드, 분류, 시각화)
5. 처음시작화면에서 "scholarly ..." 폰트의 색깔이 너무 어두운것 같어. 흰색으로 해주면 좋겠어.

코드 예시:
import requests

def get_scholar_data(author_id, api_key):
    url = "https://serpapi.com/search"
    params = {
        "engine": "google_scholar_author",
        "author_id": author_id,
        "api_key": api_key
    }
    response = requests.get(url, params=params)
    return response.json()
