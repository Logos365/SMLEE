
# 디스포저블_앱_제작

##### Step 1: 요구사항 정리 (3분)

```markdown
## 앱 요구사항

### 목적
특정 연구자의 구글스칼라 웹페이지 주소를 넣으면, 
(1) 이 연구자의 연구분야를 대분류, 중분류, 소분류로 구분을 하고,
(2) 어느 분야 연구자인지를 파악하고,
(3) 국내 및 국제적 인지도가 동일 연구분야에서 어느정도인지를 정량화 해서 보여줄수 있는 
앱을 만들어 주세요.


### 기능
1. 단계 목록 입력 (예: 문헌조사, 실험, 분석, 논문작성)
2. 각 단계별 완료 % 입력
3. 전체 진행률 자동 계산
4. 프로그레스 바 시각화

### 디자인
- 심플하고 깔끔한 UI
- 한눈에 상황 파악 가능
```
