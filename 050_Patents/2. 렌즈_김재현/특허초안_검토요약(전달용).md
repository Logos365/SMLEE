# 특허 초안 검토의견 요약

**대상**: Maxwellian 구조 VAC-free 고효율 구면 근안 디스플레이 (2026-07-06 신고서)
**작성일**: 2026-07-10

## 1. 도면부호 오류

- **완전 누락 (6건)** — 명세서·청구항에는 있으나 `figures_deck` 어느 도면에도 해당 숫자로 표기되지 않음
  - 130(광학 핀홀) → 도5에 **310**으로 다르게 표기
  - 140(곡률 조정부) → 도4에 **500**으로 다르게 표기
  - 150(아이트래커) → 도4에 **400**으로 다르게 표기
  - 160(투명 전극) → 도6에 **600**으로 다르게 표기
  - 155(제어부) → 전 도면에서 부호 자체가 누락
  - 135(흡광 격벽) → 해당 내용을 그린 도면 자체가 없음 (신규 도면 제작 필요)
- **번호 불일치 (부분 누락)**
  - 112·114·116·118(공진구조/DBR/메타표면) → 도10에는 정확하나, 전담 도면인 도3에는 **211/212, 240** 등 다른 번호로 표기
  - 120(마이크로렌즈) → 도12에는 정확하나, 도1·도2에서는 "협각 광선다발"이라는 **다른 의미**로 중복 사용됨
  - 100·110(패널/화소) → 도7(선행특허 공정 인용도)에서 그 특허 고유 부호와 의미가 충돌
- **원인 추정**: 도10~도12(최신 제작분)만 정식 부호와 일치, 도1~도7(구버전 도면)은 제목만 갱신되고 그림 본문·부호설명은 예전 번호 그대로 방치
- **조치**: 정식 출원 도면 제작 시 위 6개 누락 부호부터 정정 필수 (135는 신규 도면 추가), 도1~도3·도7의 번호 체계를 도10~12 기준으로 통일

## 2. 소재 관점 추가 제안

현재 청구항은 소자 구조(캐비티, DBR, 메타표면 등)를 명칭 수준으로만 특정하고 실제 재료 조성·물성은 없음. 아래 항목을 종속항으로 보강하면 실시가능성·차별성이 함께 강화됨.

- **DBR 재료계**: 유전체 박막쌍(TiO2/SiO2 등) 또는 반도체 박막쌍(AlGaAs/AlAs, AlGaN/GaN) 및 굴절률 차이 수치 특정
- **신축 기판 물성**: 곡률 성형 시 화소 배향 오차를 허용범위 내로 유지하는 탄성계수·파단신율 값(실리콘/폴리우레탄계) 특정
- **스트레인 완화 배선**: 아일랜드-브릿지 또는 사행형 신축 도전재료(은나노와이어, 액체금속 등)
- **마이크로 혼 콜리메이터 충전재**: 중심-주변 굴절률이 연속 변화하는 굴절률 구배(GRIN) 물질
- **투명전극 재료**: ITO/IZO/은나노와이어/그래핀 중 특정 (청구항10 보강)
- **봉지재(encapsulation)**: OLED·양자점 실시예의 무기/유기 교대적층 박막봉지 구조 (곡면 굴곡 신뢰성 확보)
- **방열층**: 그래파이트/질화붕소/금속박막 등 화소 하부 방열 구조 (온도 상승에 따른 발광효율 저하 대응)
- **흡광 격벽 재료**: 카본블랙 분산 고분자 또는 금속블랙, 반사율 수치 한정 (청구항9 보강)
- **광원별 조성 특정**: 적색은 AlGaInP계, 청·녹색은 GaN계로 구체화 (청구항18 보강)
