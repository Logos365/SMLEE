## 1. 총평 (Overall assessment)

플라즈마 메탄 열분해의 **부산물 탄소(turbostratic carbon)를 후처리 없이 그대로 SVG 광열 흡수체로 사용**하고,
성능을 "graphitic–defect hybrid 구조 ↔ 광학·광열 물성 ↔ 증발 성능"의 **structure–property–function** 관계로 설명하는 논문이다.
방향과 시의성(수소경제·turquoise H₂ 부산물 활용)은 좋다.

**현 상태는 "major revision 후 경쟁력 있음".** DFT를 포기했으므로,
논문의 성패는 이제 **(i) 메커니즘 주장을 실험적으로 얼마나 탄탄히 뒷받침하느냐**에 크게 달려 있다.
다행히 이미 측정된 UV–Vis–NIR·XRD·Raman 데이터만 **정량적으로 재분석**하면(밴드갭·Urbach 에너지·L_c·L_a·적층 층수)
추가 실험 없이도 "defect → 밴드테일 국재상태 → 광대역 흡수", "graphitic 도메인 → 빠른 비복사 완화"를 실험적으로 논증할 수 있다.
여기에 (ii) 그림-본문 정합, (iii) 효율(η)·net rate·안정성(사이클)을 채우면
좋은 전문지(*J. Mater. Chem. A*, *Carbon*, *Chem. Eng. J.*, *ACS AMI*, *Solar RRL*, *Nano Energy*)에 통과 가능하다.
성능(2.0 kg m⁻² h⁻¹ @ 1 sun)은 표 1 상단이나 분야 최고는 아니므로 **"부산물 → 무후처리 → 정량적 메커니즘"**을 판매 포인트로 삼는다.

## 3. 강점 (유지할 것)

1. **일관된 서사**: 구조(turbostratic hybrid) → 물성(광대역 흡수 + 낮은 κ) → 기능(계면 증발).
2. **분명한 차별화**: 활성화·도핑·템플릿·환원·나노구조화 **없이** 얻은 흡수체.
3. **폐자원 업사이클링 프레임**: 수소 생산 부산물 탄소 → 물정화 소재.
4. **다중 분석의 상호 정합**: HRTEM/FFT·XRD·Raman·XPS·FTIR가 "국소 graphitic + 연속 defect matrix"로 수렴.
5. **실환경 검증**: 실외 자연광 담수화, 염 배제, WHO 기준 ICP 데이터.

## 4. 반드시 고쳐야 할 문제 (Major issues)

### M1. 메커니즘 주장의 실험적 근거 보강 — **DFT 미제공 확정, 최우선**
현재 "graphitic microdomain → 광→포논 변환", "defect → 국재 전자상태 → 광대역 흡수"는 **정성적 문헌 인용**에만 의존한다.
계산이 빠지므로, **기존 데이터의 정량 재분석**으로 대체한다(대부분 추가 실험 불필요):

1. **Tauc 플롯 → 광학 밴드갭 E_g** + **Urbach 에너지 E_u** — 이미 측정한 UV–Vis–NIR 흡수/반사 데이터를 재플롯.
   - E_u가 크다(수백 meV 수준) = 무질서에서 유래한 **밴드테일(국재) 상태**가 풍부 → "defect → 흡수 문턱 저하·광대역화"의 **직접 증거**. 파장 무의존 >95% 흡수와 정합.
   - `ln(α)` vs `hν` 기울기의 역수로 E_u 산출; `(αhν)^{1/2}` vs `hν` 외삽으로 E_g(간접) 산출.
2. **XRD (002) 피크 → d₀₀₂, L_c(적층 두께), 적층 층수 N** — Scherrer식. "short-range/turbostratic"을 숫자로.
3. **Raman → L_a(면내 결정자 크기)** — Tuinstra–Koenig 또는 Ferrari–Robertson 관계식에 I_D/I_G = 0.48 대입. graphitic 도메인 크기 제시.
4. **(선택, 빠른 추가 측정) EPR/ESR 스핀밀도** — dangling bond/edge defect 밀도의 직접 지표. 가능하면 강력.

→ 이들을 "정량적 structure–property 상관표(예: E_g, E_u, L_a, L_c, N, I_D/I_G, κ)"로 묶어 서술하면 DFT 없이 메커니즘 논증이 성립.
초안 v2는 해당 문장 골격을 2.3·2.5에 배치하고 값은 `[FLAG: 재분석 필요]`로 표시함.

### M2. 그림 구성 ↔ 본문 그림 인용 불일치 (v1과 동일)
- **Figure 1**: 실제 = (a) 합성 모식도 + (b–d) SEM/HRTEM/HAADF. 본문 3.1은 "(a) 형성 모식도 + (b) 멜라민폼 통합 모식도"로 서술.
- **Figure 2**: 실제 = (a) XPS survey, (b–c) XRD, (d–e) Raman·FTIR, (f) κ, (g) 모식도. 본문 3.2는 SEM/HRTEM/HAADF를 Fig 2로 인용.
- **SI 그림 번호 offset**: 본문 "S3(XRD)·S4(BET)·S5(물 Raman)" ↔ SI 실제 "S2·S3·S4". FTIR은 본문 "S2"로 인용되나 SI에 없음.
- **조치**: 그림을 **5개로 확정**(§ 아래) 후 본문 인용 전면 재정렬. 초안 v2는 5-figure 체계로 작성.

### M3. 태양-증기 변환효율(η) 미보고
- Experimental에 Eq.(2)와 h_v=2.49 kJ g⁻¹(293 K)까지 계산했으나 Results에 η 값 없음.
- Fig 4c 값(bulk 0.11 / MF 0.87 / TC/MF 2.00 kg m⁻²)에서 net = 2.00 − 0.11 ≈ 1.9인지, 2.00이 net인지 gross인지 불명확.
- **조치**: net rate 정의 본문 명시 + η 값·계산근거 제시. η>100%면 주변부 에너지 유입으로 설명. 초안 v2는 `[η = TBD]`.

### M4. Fig 4c 시간축 단위 오류
- x축 "Time (s)", 눈금 0–70, 값 ~2 kg m⁻² → 실제 **h 또는 min**. "kg m⁻² h⁻¹"와 맞춰 수정.

### M5. 안정성·재현성 데이터 부재
- 사이클(예: 10 cycles), 장시간(≥8 h) 연속 운전, 실외 다일 반복, 코팅 박리/질량 손실 평가 없음.
- **조치**: 최소 (a) 실내 1-sun 연속 8–10 h + (b) 5–10 사이클 재사용 그래프를 Fig 5 또는 SI에 추가.
