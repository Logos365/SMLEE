## 3. 폼팩터프리전지의 핵심 함정

폼팩터프리 과제의 **필수 성과지표 1순위**:

```
전해질 상온 이온전도도: 1단계 ≥2.0 mS/cm → 2단계 ≥3.0 mS/cm
```

이 수치 달성이 **과제 전체의 핵심**이며, 이 기술을 보유한 고분자/전해질 전문 교수가
사실상 과제를 주도하게 됩니다.

### 결과적으로 발생하는 문제

- 기계연이 주관기관이더라도, 실질 핵심 기술은 공동기관(대학 전해질 교수) 담당
- 주관기관의 역할이 **집전체 구조화, 셀 조립 수준**으로 제한될 가능성
- 심사위원 관점에서 "주관기관이 왜 이 과제를 이끄는가?" 질문에 답하기 어려움
- **기업 참여 필수** → 기업 파트너를 지금 즉시 확보해야 하는 추가 부담

## 4. 선정 가능성 분석

### 리튬황전지

**강점:**
- 선행 연구가 RFP 핵심 난제를 직접 타겟 (Li-S 논문 8편 이상 보유)
- ALD라는 독보적 도구 → 심사위원에게 차별화 어필 명확
- 기업 참여 선택 → 컨소시움 구성 자유도 높음
- 주관기관이 핵심 기술 모두 주도 → 제안서 설득력 최강

**약점:**
- 전고체 리튬황은 전 세계적으로 난이도 최상급 과제
- 예산이 폼팩터프리 대비 작음 (90억 vs 135억)

### 폼팩터프리전지

**강점:**
- 예산이 50% 더 큼
- 반고체 기반으로 전고체보다 상대적으로 목표 달성 쉬움
- 응용 분야(로봇, 웨어러블)가 명확해 평가자 어필 용이

**약점:**
- 핵심 기술(전해질)이 선생님 전문성과 불일치
- 기업 참여 필수 → 즉각적인 산업계 파트너 확보 필요
- 중국이 반고체전지 상용화 주도 → 기술 차별화 어려움
- 주관기관 역할이 제한될 위험

```
폼팩터프리 = 예산은 크지만, 핵심 기술이 맞지 않음
              주관기관이 되어도 사실상 조연 역할
              기업 파트너 확보 부담 즉시 발생

              제안서 설득력 최강, 선정 가능성 높음
              선행 연구로 진입장벽 이미 구축
```

## 6. 폼팩터프리 활용 방안 (차선책)

리튬황전지를 주관으로 신청하더라도 폼팩터프리를 완전히 포기할 필요는 없습니다.

**방안 1: 공동연구기관으로 참여**
- 폼팩터프리 과제에서 **셀 구조 설계, 3D 집전체, ALD 계면 코팅** 역할로 공동기관 참여
- 단, 공동기관 연구책임자도 1개 과제 제한에 해당하므로 규정 재확인 필요

**방안 2: 리튬황전지 수행 후 후속 과제로**
- 리튬황 과제에서 확보한 ALD 계면 기술 + 구조화 집전체 기술을
- 폼팩터프리 후속 과제 (2028년 이후) 제안 시 핵심 선행 연구로 활용
