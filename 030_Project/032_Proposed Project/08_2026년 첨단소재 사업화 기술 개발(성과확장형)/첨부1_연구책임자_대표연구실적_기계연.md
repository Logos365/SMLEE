**기관명:** 한국기계연구원 (KIMM)  
**연구책임자:** 이승모

## □ 선행 원천기술

> 주관연구개발기관 필수 작성 (최대 5건)  
> 본 과제(10 kg급 고속·대면적 ALD 공정 기반 고전압 나트륨이온전지용 계면 안정화 기술 및 1Ah급 파우치셀 개발)의 사업화 기반이 되는 선행 원천기술

---

### [선행 원천기술 1] ZnF₂ ALD 박막 기반 전기화학적 계면 안정화 기술

원자층 증착(ALD) 공정으로 ZnF₂ 초박막(수십~90 nm)을 금속 집전체 및 음극 표면에 균일 증착하고, 충방전 초기 전기화학적 활성화 과정에서 LiZn 합금 및 LiF 계면층으로 전환되어 리튬/아연 핵생성을 균일화하고 덴드라이트 성장을 억제하는 기술. 대칭형 셀 기준 3 mA cm⁻² / 3 mAh cm⁻² 조건에서 900시간 이상의 장기 안정성을 확인하였으며, 이는 ALD 박막이 배터리 음극 계면 안정화에 직접 활용될 수 있음을 실증한 원천 기술임.

| 구분 | 내용 |
|------|------|
| 실적 유형 | 논문 |
| 근거 논문 | Taming Lithium Nucleation and Growth on Cu Current Collector by Electrochemical Activation of ZnF₂ Layer |
| 저널 | Advanced Science (ISSN: 2198-3844) |
| 게재년월 | 2025년 5월 |
| 역할 | 교신저자 |

---

### [선행 원천기술 2] 기상 침투(Vapor Phase Infiltration, VPI) 기반 나노복합 소재 제조 원천 기술

ALD 전구체를 기상 상태로 공급하여 다공성 고분자·생체 기재 내부에 금속 산화물 나노 성분을 원자 수준으로 균일 분산·침투시키는 기술. 기존 습식 공정 대비 핀홀 없는 균일 코팅이 가능하며, 거미줄(spider silk) 소재에 최초 적용하여 인장 인성(toughness)을 획기적으로 향상시킨 결과를 Science지(2009)에 게재. 본 과제의 나트륨이온전지 양극재 표면 ALD 공정 설계의 이론적·공정적 기반을 제공하는 핵심 원천 기술임.

| 구분 | 내용 |
|------|------|
| 실적 유형 | 논문 |
| 근거 논문 | Greatly increased toughness of infiltrated spider silk |
| 저널 | Science (ISSN: 0036-8075) |
| 게재년월 | 2009년 4월 |
| 역할 | 제1저자 |

---

### [선행 원천기술 3] TiO₂ ALD 코팅 기반 배터리 전극 계면 엔지니어링 기술

ALD로 증착된 TiO₂ 나노 코팅층이 전극 표면에서 전해질과의 부반응을 차단하고, 황화 처리 시 TiS₂/TiO₂ 헤테로구조를 형성하여 이온 전도성 및 전기화학 반응 속도를 동시에 향상시키는 기술. 본 과제에서 나트륨이온전지 양극재(고-Ni 층상 산화물)에 적용 예정인 TiO₂ ALD 코팅의 공정 윈도우(150~300°C, TTIP 또는 TiCl₄ 전구체 기반) 수립의 직접적 선행 기술 근거를 제공함.

| 구분 | 내용 |
|------|------|
| 실적 유형 | 논문 |
| 근거 논문 | Accelerated Sulfur Evolution Reactions by TiS₂/TiO₂@MXene Host for High‐Volumetric‐Energy‐Density Lithium–Sulfur Batteries |
| 저널 | Advanced Functional Materials (ISSN: 1616-301X) |
| 게재년월 | 2023년 8월 (확인 필요) |
| 역할 | 교신저자 |
| 비고 | 피인용 141회 |

---

### [선행 원천기술 4] 바나듐 산화물(V₂O₅/V₂O₃₋ₓ) 기반 전극 표면 코팅 및 계면 특성 제어 기술

탄소 기반 전극 표면에 VC/V₂O₃₋ₓ 하이브리드 나노입자를 정밀 코팅하여 유사 용량성(pseudocapacitive) 특성을 부여하고, 전극 반응 속도 및 에너지 저장 성능을 향상시키는 기술. 바나듐 산화물 계면 화학에 대한 깊은 공정 이해를 보유하고 있으며, 이는 본 과제에서 VTIP [VO(OiPr)₃] 전구체 기반 V₂O₅ ALD 공정 레시피 개발의 원천 지식으로 직접 활용됨.

| 구분 | 내용 |
|------|------|
| 실적 유형 | 논문 |
| 근거 논문 | Porous carbon textile decorated with VC/V₂O₃₋ₓ hybrid nanoparticles for high-performance Li–S batteries |
| 저널 | Energy Storage Materials (ISSN: 2405-8297) |
| 게재년월 | 2022년 (확인 필요) |
| 역할 | 교신저자 |
| 비고 | 피인용 70회 |

### [선행 원천기술 5] 배치식 ALD 기반 공정 레시피 체계화 및 연속식 스케일업 이전 기술

4인치급 배치식 ALD 장비 2대를 활용하여 금속 산화물(TiO₂, Al₂O₃, V₂O₅, ZnO) 전구체별 공정 온도, pulse/purge 시간, 사이클당 성장률(Growth Per Cycle, GPC) 등 ALD 공정 윈도우를 체계적으로 확립하는 기술. 배치식 장비에서 확립된 자기제한(self-limiting) 반응 조건 및 공정 파라미터 DB를 연속식 분말 ALD 장비로 이전하는 스케일업 파이프라인을 구축하며, 이를 통해 kg급 이상 배터리 양극재의 대량 정밀 코팅이 가능한 산업화 연계 원천 기반 기술로 기능함.

| 구분 | 내용 |
|------|------|
| 실적 유형 | 논문 |
| 근거 논문 | Ultralight Pt-ALD-modified graphene aerogel achieving aluminum-class thermal resistance at 12% mass |
| 저널 | Materials & Design (ISSN: 0264-1275) |
| 게재년월 | 2025년 (확인 필요) |
| 역할 | 교신저자 |

### 논문별 본 과제 연관성 요약
