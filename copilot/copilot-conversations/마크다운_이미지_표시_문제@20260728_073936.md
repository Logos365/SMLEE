Let me explain the issue and solution.</think>## 이미지가 안 보이는 이유

현재 노트에서 이미지가 아래와 같은 형식으로 삽입되어 있습니다:

```
![](./images/media/image1.png)
```

이 방식은 **상대 경로(relative path)** 를 사용한 표준 마크다운 문법인데, Obsidian에서는 이 방식이 제대로 작동하지 않는 경우가 많습니다.

---

## Obsidian에서 이미지를 넣는 올바른 방법

Obsidian에는 두 가지 이미지 삽입 방식이 있습니다:

### ✅ 방법 1: Obsidian 내부 링크 (권장)
이미지 파일을 Vault 내부에 저장한 후 아래 형식 사용:

```
![[image1.png]]
```

### ✅ 방법 2: 표준 마크다운 (웹 URL용)
웹에 있는 이미지의 경우:

```
![설명](https://example.com/image.png)
```

---

## 현재 문제의 해결 방법

현재 노트의 이미지들(`image1.png`, `image2.png` 등)을 보이게 하려면:

1. **이미지 파일들을 Vault 폴더 안으로 이동** (예: `04_Publication/04_005_Turbostratic Carbon_Uyen_Dung/images/media/` 경로로)
2. Obsidian 설정에서 **"Use [[Wikilinks]]"** 옵션이 켜져 있으면 아래처럼 변경:

```
![[image1.png]]
```

3. 또는 Obsidian 설정 → Files & Links → **"New link format"을 "Relative path to file"** 로 설정하면 `![](./images/media/image1.png)` 형식도 작동할 수 있습니다.

---
