# 그림02 협력 파이프라인 — content-organizer 분석 결과

## 메타데이터
- **페이지**: 5페이지, 24페이지
- **목적**: 기계연 × 대성기계 기술 이전·피드백 폐루프 파이프라인
- **저장 예정 이미지**: `그림02_협력파이프라인.png`

---

## Phase 1 — 문서 분석

- **문서 유형**: 정부 R&D 과제 선정평가 발표자료
- **핵심 주제**: 배치식 ALD 레시피 개발(기계연) → 연속식 적용(대성기계) → 분석·피드백의 폐루프 협력 파이프라인
- **대상 청중**: 기술 심사위원, 정책 담당자

---

## Phase 2 — 슬라이드 구성

```
[상단] 메인 타이틀
       "한국기계연구원 × 대성기계공업 기술 이전·피드백 순환 체계"

[중앙 Cycle 다이어그램 — 시계 방향]

  ① [12시] 배치식 ALD 레시피 개발
           TiO₂, Al₂O₃, V₂O₅, ZnO     [기계연]
              ↓ 레시피 패키지 이전
  ② [3시]  연속식 분말 ALD 코팅
           FBR → OPERIO 10 → 10 kg/h   [대성기계]
              ↓ 코팅 시료 제공
  ③ [6시]  HR-TEM/EELS/XPS 원자 분석   [기계연]
              ↓ 분석 결과·피드백
  ④ [9시]  레시피 미세 조정             [기계연+대성기계]
              → ①로 귀환 (루프)

[하단 강조 박스 2개]
  ★ RTD(체류시간 분포) 기반 배치→연속식 레시피 변환 방법론 최초 확립
  ★ 국내 유일 배치식 ALD 레시피↔연속식 분말 ALD 협력 모델
```
