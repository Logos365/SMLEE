# ALD 코팅 기술적 난제 및 해결 방안 — PPT 슬라이드 초안

> **슬라이드 위치**: 8페이지 "기술난제 및 해결방안" 섹션 내 ALD 전용 슬라이드 (신규 추가 권장)  
> **슬라이드 목적**: 심사위원에게 ALD 코팅의 핵심 기술적 난제를 명확히 제시하고, 본 컨소시엄의 차별화된 해결 역량을 설득력 있게 전달  
> **레이아웃**: 3-열 구성 (난제 3개 × 해결방안 3개) + 하단 요약 박스

## 슬라이드 제목

> **"연속식 분말 ALD 코팅의 3대 기술적 난제와 해결 방안"**  
> 부제: 한국기계연구원 + 대성기계공업 협력 모델의 핵심 기술적 근거

## [상단 헤더 박스] — 전체 배경 설명 (1~2줄)

> ALD(원자층 증착)는 SIB 양극재 계면 안정화에 이상적이나, **배치식→양산 이전·코팅 활성 제어·대량 균일 코팅** 세 가지 난제가 산업화의 핵심 장벽으로 작용한다.

## [3-열 메인 콘텐츠]

---

### 열 1 — 난제 ①: 배치식 → 연속식 공정 이전 불가

```
┌─────────────────────────────────┐
│  🔴 난제 ①                       │
│  배치식(정지반응) ↔ 연속식(비행반응) │
│  공정 환경 근본적 차이             │
└─────────────────────────────────┘
         ↓
┌─────────────────────────────────┐
│  🟢 해결방안                      │
│  RTD 기반 정량적 변환 알고리즘      │
│  (μ - 2σ ≥ t_pulse)             │
└─────────────────────────────────┘
```

**난제 상세**
- 배치식: 분말이 반응기 내 정지 → Pulse 시간 = 전구체 노출 시간
- 연속식: 분말이 공압 이송 중 비행 → Pulse 시간 ≠ 노출 시간
- 기존 배치식 레시피를 연속식에 그대로 적용 시: **두께 편차 > 30% 이상 발생** → 재현성 확보 불가

**해결 방안 (기계연 × 대성기계 협력)**
- **체류시간 분포(RTD)** 측정 → 분말의 최소 체류시간(μ - 2σ) 확보
- 배치식 Pulse 시간 → 연속식 최소 체류시간 1:1 매핑 알고리즘
- 기계연이 레시피 확립 → 대성기계 RTD 측정값 기반 변환 → 연속식 이전
- **세계 최초 분말 ALD 배치→연속식 정량적 이전 방법론 확립**

### 열 2 — 난제 ②: V₂O₅ 코팅층의 전기화학적 활성 위험

```
┌─────────────────────────────────┐
│  🔴 난제 ②                       │
│  V₂O₅ 작동전압(2.0–3.5V)이        │
│  SIB 양극 운전전압과 중복          │
└─────────────────────────────────┘
         ↓
┌─────────────────────────────────┐
│  🟢 해결방안                      │
│  ALD Å 수준 두께 제어 (1–2 nm)    │
│  + V₂O₅/TiO₂ 이중층 설계         │
└─────────────────────────────────┘
```

**난제 상세**
- V₂O₅는 Na 잔류물 제거 + 혼합 이온·전자 전도성(MIEC) 등 탁월한 코팅 효과
- **그러나** 작동 전압(2.0–3.5V)이 SIB 양극 전압범위(2.0–4.2V)와 대부분 겹침
- 두꺼운 코팅 시(> 3 nm): 독립 전극으로 반응 → 전압 프로파일 교란 → **오히려 성능 저하**
- 습식·건식 공정으로는 두께 제어 한계 → Å 수준 정밀 제어 필수

**해결 방안**
- **ALD의 자기제한 반응**: 1 사이클 = 정확히 0.3–0.6 Å → 5–10 사이클 = 1–2 nm 정밀 제어
- **비정질(amorphous) VOₓ 선호**: 결정성 V₂O₅보다 SIB 환경에서 더 안정적
- **V₂O₅(내층)/TiO₂(외층) 이중층**: TiO₂ 외층이 전해질 직접 접촉 차단 → V₂O₅ 전기화학 활성 억제
  - Rct(계면저항): 202 Ω (V₂O₅ 단독 688 Ω 대비 **1/3 수준** 달성) *(Kim et al., ACS AMI, 2024)*

### 열 3 — 난제 ③: 대량 양산 시 코팅 균일도 확보

```
┌─────────────────────────────────┐
│  🔴 난제 ③                       │
│  분말 입자 뭉침(Agglomeration)·   │
│  정체구간(Dead Zone)·            │
│  비균일 전구체 노출               │
└─────────────────────────────────┘
         ↓
┌─────────────────────────────────┐
│  🟢 해결방안                      │
│  3단계 스케일업 + 공압 이송         │
│  + 구간 분리형 반응기 구조          │
└─────────────────────────────────┘
```

**난제 상세**
- g 수준 배치식 → 10 kg/h 양산: 처리량 **약 3,000배 이상 증가**
- 분말 뭉침 → 코팅 면적 감소 → 일부 입자 미코팅 발생
- 정체 구간 발생 → 과코팅(두꺼운 부분) vs. 미코팅 혼재
- 전구체 가스 분포 불균일 → GPC 편차 증가 → 품질 저하

**해결 방안 (대성기계 OPERIO 10)**
- **공압 이송 기반 연속 분산**: 분말이 기류에 의해 항상 분산 유지 → 뭉침 방지
- **구간 분리형 반응기**: 전구체 구간 → 퍼지 구간 → 반응제 구간 물리적 분리 → 교차 오염 방지
- **RTD 기반 실시간 공정 드리프트 보정**: 연속 운전 중 두께 편차 통계적 모니터링
- **3단계 스케일업**: FBR(≤10%) → OPERIO 10 Pilot(≤7%) → 양산(≤5%) 단계적 검증

## [하단 요약 박스 — 3난제 × 해결 매핑 테이블]

| 난제 | 핵심 원인 | 기술적 해결책 | 담당 기관 | 검증 지표 |
|:----:|:--------:|:----------:|:--------:|:--------:|
| ① 배치→연속 이전 | 공정 환경 근본 차이 | RTD 정량 변환 알고리즘 (μ-2σ ≥ t_pulse) | 기계연 + 대성기계 | GPC 재현성 ≤5% (3차년도) |
| ② V₂O₅ 활성 제어 | 전압 범위 중복 | ALD 두께 1–2 nm + 비정질 VOₓ + TiO₂ 외층 | 기계연 | 계면저항 ≤50 Ω·cm² |
| ③ 양산 균일도 | 분말 뭉침·정체구간 | 공압이송 분산 + 구간분리 반응기 + RTD 모니터링 | 대성기계 | 두께 편차 ≤5% @ 10 kg/h |

## [강조 박스 — 심사위원 어필 포인트]

> **본 컨소시엄만이 이 3가지 난제를 동시에 해결할 수 있는 이유**
>
> ✅ 기계연: 20년+ ALD 연구 역량 — **Å 수준 두께 제어** 기술 내재화  
> ✅ 대성기계: 국내 유일 **연속식 분말 ALD 장비(OPERIO 10)** 보유  
> ✅ 협력 모델: 배치식 레시피 개발(기계연) → **RTD 기반 연속식 이전(세계 최초)** → 10 kg/h 실증

## 그림 추천

1. **좌측 상단**: V₂O₅/TiO₂ 이중층 구조 모식도 (내층 V₂O₅ + 외층 TiO₂ + 전해질 차단)

3. **우측**: 대성기계 OPERIO 10 장비 외관 사진 또는 공압 이송 단면도
