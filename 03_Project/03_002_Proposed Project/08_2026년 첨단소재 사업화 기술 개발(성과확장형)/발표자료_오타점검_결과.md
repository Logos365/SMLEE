## 2. 권장 수정 사항 (용어·표현 불일치)

### 🟡 표현 불일치 2: "소듐이온전지" 혼용 (추가 확인)
- **위치**: 전체 발표자료 내 용어 혼용 가능성 있음
- **확인 필요**: "소듐이온전지", "나트륨이온전지", "NaIB", "SIB" 표현 통일 여부
- **권장**: 한글 표기는 `나트륨이온전지`로 통일, 영문 약어 `SIB` 병기 가능

---

### 🟡 표현 불일치 3: 기술이전 금액 단위
- **위치**: 15페이지 (03| 연구개발목표)
- **원문 확인 필요**: 기술이전 금액 단위 "건" 사용 여부
- **수정**: `건` → `억원`으로 변경
- **비고**: 김현수 박사님 코멘트 "기술이전 금액의 단위는 건에서 억원으로 수정" — 반드시 수정

---

### 🟡 표현 불일치 4: V2O3, NbO5 표기 오류 가능
- **위치**: 18페이지
- **원문**: `V2O3,TiO2,NbO5의Precu`
- **수정 검토**: V₂O₅ (오산화바나듐)인데 V₂O₃로 표기된 것인지 확인 필요
  - 본 과제 대상 소재는 V₂O₅임 (V₂O₃는 삼산화바나듐, 다른 소재)
  - NbO5는 Nb₂O₅ (오산화이나이오브)가 맞는 화학식 — 수정 필요
- **비고**: 화학식 오류는 심사위원의 신뢰도를 크게 훼손함

## 3. 확인 권장 사항

### 🟢 확인 1: 연구목표 최종목표 문구
- **위치**: 15페이지 (연구개발목표 KPI 표)
- **확인 사항**: 셀 용량 0.8Ah → 1.0Ah 증가, 용량유지율 2·3차년도 동일(80%) 여부
- **비고**: 김현수 박사님 코멘트 "0.8Ah에서 1.0Ah 증가가 의미 있는 목표치인지?" — 발표 시 근거 설명 준비 필요

### 🟢 확인 2: 씨오알엔 관련 문구
- **위치**: 27~29페이지
- **확인 사항**: "셀 조립라인 투자 예상 60억원", "셀 조립까지 단계적 확장" 등 문구
- **비고**: 김현수 박사님 "현재 기구축되어 있다는 전제하에 과제 진행이 바람직함" — 문구 삭제 또는 수정 필요

### 🟢 확인 3: 발표자료 페이지 수 통일
- **위치**: 27페이지 (씨오알엔)
- **확인 사항**: 다른 기관과 동일하게 1페이지로 통일 여부
- **비고**: 김현수 박사님 코멘트 "다른 기관과 동일하게 1페이지로 통일"

### 🟢 확인 4: 별첨 페이지 번호 "0X" 표기
- **위치**: 45~50페이지 (별첨 슬라이드)
- **원문**: `(별첨) 0X| ALD 코팅의기본기대효과`, `(별첨) 0X| 문헌자료` 등
- **수정 필요**: "0X"를 실제 번호로 변경
- **비고**: 임시 번호 그대로 제출 시 완성도 낮아 보임
