**4. 연구과제의 최종 목표 (작성안)**

+-----------------------------------------------------------------------+
| **\[ 최종 목표 \]**                                                   |
|                                                                       |
| 본 연구는 **애노드-프리 리튬-황(Li-S) 배터리**의 근본적 한계인        |
| 리튬(Li) 인벤토리 손실 및 황(S) 인벤토리 손실 메커니즘을 규명하고,    |
| 이를 동시에 억제하는 혁신 전략을 한·독 공동 연구를 통해 개발하는 것을 |
| 최종 목표로 한다.                                                     |
|                                                                       |
| **■ 한국 팀 (KIMM, 음극 담당):**                                      |
|                                                                       |
| > 원자층 증착(ALD) 기반 초박형 인공 코팅 소재(MxFy, MxOy)를 개발하고, |
| > 3D 다공성 구조 집전체를 설계하여 균일한 리튬 도금/탈리를            |
| > 구현함으로써, 200 사이클 이상에서 면적 용량 ≥ 5 mAh cm-2 및 쿨롱    |
| > 효율(CE) ≥ 99.5%를 달성한다.                                        |
|                                                                       |
| **■ 독일 팀 (Uni. Freiburg / Fraunhofer ISE, 양극 담당):**            |
|                                                                       |
| > 개질된 탄소 호스트 내 나노-Li2S 기공 제한 전략(Pore Confinement)과  |
| > SnS2 결함 활성 사이트를 통해 Li2S 산화 전위를 낮추고 반응 속도론을  |
| > 개선하며, 분리막 코팅을 통해 셔틀 효과를 억제하고 추가 Li2S 저장    |
| > 기능을 부여한다.                                                    |
|                                                                       |
| **■ 한·독 공동 (풀셀 통합 평가):**                                    |
|                                                                       |
| > 한국 팀의 개질 집전체와 독일 팀의 합성 캐소드를 결합한 애노드-프리  |
| > Li-S 풀셀을 제작·평가하여, 실용 황 로딩(\> 5 mg cm-2) 조건에서      |
| > 에너지 밀도 ≥ 500 Wh kg-1, 200\~300 사이클에서 용량 유지율 ≥        |
| > 70\~80%를 달성하는 장수명 애노드-프리 리튬-황 배터리 원천기술을     |
| > 확립한다.                                                           |

**종합 검토 의견**

본 연구 제안서(LI-INVENT)는 애노드-프리 리튬-황 배터리 분야에서
세계적으로 선도적인 연구 가설(리튬·황 인벤토리의 상호 결합)을 바탕으로
한·독 양측의 강점을 상호 보완적으로 결합하는 매우 우수한 국제공동연구
구조를 갖추고 있습니다.

현재 PPT 개요 자료는 기술적 내용이 충실하게 구성되어 있으나, 국문
연구계획서를 실제로 작성하기 위해서는 다음 사항들이 반드시 보완되어야
합니다:

-   국제공동연구의 필요성 및 한·독 시너지 효과에 대한 구체적 서술
    (제안서 1항·6항)

-   연차별 정량 성과 목표 및 연구비 적정성 설명 기재 (제안서 2항·3항)

-   오타 수정: \'Coloumbic\' → \'Coulombic\' 및 기타 영문 표현 일관성
    확보

-   PPT 슬라이드의 국문 제안서 내 내용 이식 작업 필요 (특히 연구
    배경·가설·전략 부분)

-   독일 측 연구자 인적사항 및 역할 분담 표 작성 완료

가상 연구팀(민수: 데이터 분석, 가영: 전략 제안, 하윤: 비판적 검토, 민지:
실행 계획)의 종합 의견을 반영하여 위 개선 방향을 제안하였습니다. 본 검토
보고서를 바탕으로 국문 연구계획서를 충실히 작성하시면 선정 가능성을 크게
높일 수 있을 것으로 판단됩니다.
