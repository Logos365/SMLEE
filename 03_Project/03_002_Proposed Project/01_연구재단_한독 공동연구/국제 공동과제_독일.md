2. 두 국가의 연구기간이 협업을 하면, 큰 시너지 효과를 기대할수 있다는 메세지를 전달해야 합니다.
3. 총연구 기간은 3년이고,  각 연구 기간별로 연구비는 1.5억/연 입니다.
4. 연차별로, 각 기관이 어떻게 협업을 해나가는지, 유기적으로 잘 연결되어 있는지를 보여주여야 합니다.

위 PDF화일을 전반적으로 리뷰를 해주세요.
