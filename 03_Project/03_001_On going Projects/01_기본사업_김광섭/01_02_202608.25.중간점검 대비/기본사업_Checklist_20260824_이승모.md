### 2차년도 내용

- [x] **1차 CCD DOE (2026-03-18, 795 ℃ 고정)**
	- 2인자(H2 10~30, CH4 20~60 sccm) 13회 실험, 설계·분석 김재현, 실험 김경식
	- 면저항 평균 모형 유의하지 않음 (R²=0.44)
	- 주요이슈: 중심점 CV 48.6%로 공정 재현성 문제 발견, 중심점이 안장점 위에 위치
- [x] **파단 온도 기반 합성 온도 재설정 (2026-05-18)**
	- 2호기 파단 온도 798 ℃ 최적점 도출 (T-CVD 경험칙 melting -80~90 ℃와 부합)
	- 주요이슈: 가스·시간 고정, 온도 단일변수 재최적화
- [x] **2차 CCD 재분석 (2026-07-31, 798 ℃)**
	- 재현성 해소: 중심점 CV 48.6% → 11.3% (이상 run 제외 시 4.5%), pyrometer 윈도우 교체 효과와 부합
	- 곡면 안장점 → 최소점형 전환 (R²=0.947), 온도 3 ℃가 곡면 위상을 바꿈 → 온도가 지배 인자
	- 1차 권고점 (H2 30, CH4 20): 2차에서 최악 성능, 저CH4 영역 회피 확정
- [x] **최소점 검증 실험 및 평탄 고원 확정 (2026-08-04~05)**
	- 모형 최소점 (H2 23, CH4 52) 검증 2 run: 220.1 Ω/sq (CV 8.6%, 전 run 중 최저 균일도) / 259.2 Ω/sq
	- 깊은 최소점 기각 (예측 127.9 vs 실측 239.6 Ω/sq) → H2 20~34 × CH4 40~68 평탄 고원(200~260 Ω/sq) 확정
- [x] **3차 실험 계획 v3 확정 (2026-08-05)**
	- 온도를 정식 인자로 승격한 3요인(온도·H2·CH4) 3수준 면중심 CCD
	- 1차(795 ℃) 데이터는 쿼츠 오염에 의한 실효 온도 불확실성으로 재사용 전면 배제, 신규 16 run (설계 14 + 블록 보정 2)
	- 김경식 책임 3차 실험 계획법 수행 중
- [x] **다구치 강건 설계 적용성 검토 (2026-08-05)**
	- 비강건성 주범은 조건이 아니라 run 수준 잡음(쿼츠 상태 등)으로 진단
	- 전면 L9 전환 대신 3차 CCD에 S/N 응답을 얹는 이중 RSM 하이브리드(추가 실험 0) 권고
